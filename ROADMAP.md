# Roadmap

This roadmap contains future work only. It does not promise a delivery date or order.

## Planned directions

- Improve first-run onboarding, configuration diagnostics, and operator health checks.
- Strengthen meeting interruption atomicity and recovery of partial stop/cancel states.
- Expand operator tooling for runtime inspection and bounded maintenance actions.
- Add an authenticated TLS/WSS deployment path for Capture Hub remote connections.
- Improve distributed TTS deployment, diagnostics, discovery, and failover guidance.
- Support optional multi-emotion voice references without distributing voice assets.
- Consolidate Agent Coordinator responsibilities and orchestration paths.
- Add contributor documentation for setup, testing, architecture, and release conventions.
