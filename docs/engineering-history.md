# Engineering History

The public repository uses exactly eight curated engineering milestones. This is a
public progression, not a reproduction of private development history.

## 1. Moxue Discord assistant core

Established the Discord assistant foundation: configuration, storage, conversation,
music, voice, slash commands, and application structure.

## 2. Extensible Tool Gateway

Added the Tool Gateway framework and the boundary used to discover and invoke external
tools without hard-wiring each integration into the conversational core.

## 3. Meeting recorder and Capture Agent

Added meeting recording/capture workflows, Capture Agent, Capture Hub interfaces, and
supporting meeting utilities.

## 4. Agent core and distributed Moxue TTS

Introduced the agent/event foundation and distributed TTS worker architecture,
including authenticated routing and the external GPT-SoVITS boundary.

## 5. Memory V2

Added scoped memory storage, privacy gates, passive/manual memory flows, inspection
controls, and structured memory behavior.

## 6. Web research and image tools

Added explicit web-research and image-generation tools, artifact delivery, provider
boundaries, and externally sourced/generated content safety checks.

## 7. Social intelligence and reviewed meeting learning

Expanded social/session/shared/domain-aware memory behavior together with meeting
feedback and article-oriented workflows.

## 8. Chat Style, knowledge enrichment, and public hardening

Added Chat Style learning/controls, personal and guild knowledge enrichment, bounded
public-term lookup, model-routing improvements, and the documentation/security/license
work for the first public source release.
